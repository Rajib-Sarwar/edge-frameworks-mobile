# edge-frameworks-mobile v0.2.0

v0.2.0 turns the project from a generation-only baseline into a usable local RAG framework for native iOS and Android apps.

## Highlights

- Apple Foundation Models structured output on iOS.
- Cross-platform `EdgeTool` abstraction and Apple Foundation Models tool calling.
- Provider-neutral local RAG primitives on Swift and Kotlin.
- Real on-device embeddings:
  - Apple Natural Language sentence embeddings on iOS.
  - MediaPipe Text Embedder / Universal Sentence Encoder on Android.
- Persistent local vector storage with `EdgeFileVectorStore`.
- Portable document chunking with `EdgeTextChunker`.
- Native document import for TXT, Markdown, JSON, and text-based PDFs.
- PDF source and page metadata preserved through retrieval.
- End-to-end local RAG demos on both platforms.

## PDF scope

v0.2.0 extracts existing text from PDFs. Scanned or image-only PDFs are not OCR'd.

OCR, DOCX, HTML, image ingestion, richer collection management, and advanced re-indexing are planned for later milestones.

## Platform notes

### iOS

- Apple Foundation Models for generation.
- Apple Natural Language for sentence embeddings.
- PDFKit for text-based PDF ingestion.
- Persistent vector data stored in app-local Application Support.

### Android

- Gemini Nano through ML Kit GenAI Prompt API for generation.
- MediaPipe Text Embedder with Universal Sentence Encoder for embeddings.
- PdfBox-Android for text-based PDF ingestion.
- Persistent vector data stored in app-local storage.

## Validation

The repository's protected `main` branch requires both:

- `ios-test`
- `android-test`

before pull requests can merge.

No prebuilt package artifacts are attached to this release. v0.2.0 is released as source through the repository tag.
