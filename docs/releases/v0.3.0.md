# edge-frameworks-mobile v0.3.0

v0.3.0 expands the local-first RAG layer from basic document retrieval into a more complete on-device knowledge-management pipeline for native iOS and Android apps.

## Highlights

- Knowledge collections through `EdgeKnowledgeCollection`.
- Collection-scoped retrieval and vector filtering by document, collection, and metadata.
- Document removal, collection clearing, and document re-indexing.
- Persistent knowledge collection/source catalog through `EdgeFileKnowledgeCatalog`.
- SHA-256 content fingerprinting with `EdgeContentFingerprint`.
- Source-level incremental re-indexing through `EdgeIncrementalIndexer`:
  - unchanged sources skip embeddings and indexing;
  - changed sources replace their previously indexed chunks.
- Scanned/image-only PDF OCR fallback:
  - Apple Vision on iOS;
  - bundled ML Kit Text Recognition on Android.
- DOCX ingestion:
  - ZIPFoundation + WordprocessingML on iOS;
  - platform ZIP/XML parsing on Android.
- HTML ingestion:
  - platform HTML parsing on iOS;
  - jsoup on Android.
- Standalone image OCR ingestion:
  - ImageIO + Apple Vision on iOS;
  - ML Kit Text Recognition on Android.
- Updated end-to-end RAG demos on both platforms.

## Local knowledge pipeline

```text
TXT / Markdown / JSON / PDF / DOCX / HTML / image
                    ↓
             EdgeDocument
                    ↓
             EdgeTextChunker
                    ↓
         on-device text embeddings
                    ↓
           EdgeFileVectorStore
                    ↓
     EdgeKnowledgeCollection / source catalog
                    ↓
       fingerprint change detection
                    ↓
     local retrieval + model generation
```

## Scope notes

- Image ingestion is OCR-focused. v0.3.0 does not include semantic visual embeddings, image captioning, or general scene/object understanding.
- Incremental indexing is source-level. Any content change re-indexes that source as a unit rather than diffing individual pages or sections.
- DOCX ingestion focuses on the main `word/document.xml` body. Headers, footers, comments, tracked-change semantics, and embedded media are not modeled separately.
- PDF OCR is used only when embedded PDF text is unavailable for a page.

## Platform notes

### iOS

- Apple Foundation Models for generation.
- Apple Natural Language sentence embeddings.
- PDFKit for PDF ingestion.
- Apple Vision for scanned-PDF and standalone-image OCR.
- ZIPFoundation for DOCX package access.
- Persistent vectors and knowledge catalog stored in app-local files.

### Android

- Gemini Nano through ML Kit GenAI Prompt API for generation.
- MediaPipe Text Embedder / Universal Sentence Encoder for embeddings.
- PdfBox-Android for PDF ingestion/rendering.
- Bundled ML Kit Text Recognition for scanned-PDF and standalone-image OCR.
- Platform ZIP/XML parsing for DOCX and jsoup for HTML.
- Persistent vectors and knowledge catalog stored in app-local files.
